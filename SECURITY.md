# Security Policy

## Supported versions

| Version | Supported |
| ------- | --------- |
| 1.x     | Yes       |

## Reporting a vulnerability

Open a **private** report via GitHub: repo page → Security → Advisories →
"Report a vulnerability". Do not open a public issue for security bugs.

We aim to acknowledge within 7 days. Please allow time for a fix and release
before public disclosure.

Note: your voice audio is sent to Groq Cloud for transcription (see README
privacy note). Never include API keys or personal audio in reports.
