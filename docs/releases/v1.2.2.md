## Install

Download **G4Speak-Setup-1.2.2.exe** and run Setup. Existing API settings and personal vocabulary are retained. The portable **G4Speak.exe** and **SHA256SUMS.txt** are also included.

## Transcription quality

- Speech recognition continues to use the full **Whisper Large-v3** through Groq.
- Choose **Transcription Mode > Enhanced** to enable contextual proofreading with **Qwen 3.8 27B**, now using low reasoning effort and a usable 6-to-20-second allowance within the overall deadline.
- Improve Thai-English phonetic spelling correction, with regression coverage for `fonder` versus `folder` and `sub` versus Thai vocabulary words. Corrections depend on sentence context; genuine technical uses of `sub` remain valid.
- Include personal vocabulary when proofreading, process long transcripts in bounded chunks, and preserve original text when checks reject changes or the service is unavailable.
- Notify users briefly when enhanced proofreading is unavailable. Pause requests for 60 seconds after rate limits rather than silently making repeated failing requests.

Existing configurations with `GROQ_REFINER=false` remain in **Standard** mode. Select **Enhanced** from the tray menu to use the additional proofreading stage. Accuracy is not guaranteed; names and uncommon terms benefit from the Personal Dictionary.

## Interface and project organization

- Use formal English menus: **API Credentials**, **Personal Dictionary**, **Transcription Mode**, **Recognition Language**, and **Launch at Sign-in**.
- Enter API keys in a native masked form instead of editing a configuration file. Display actionable service messages instead of internal error details.
- Organize source into audio, text, and UI packages; separate build scripts, Windows packaging, tests, and documentation.
- Exclude the unused local language model dependency from the Windows installer and standard build dependencies.
