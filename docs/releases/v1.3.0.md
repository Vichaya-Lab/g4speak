## Install

Download **G4Speak-Setup-1.3.0.exe** and run Setup. Existing API settings and personal vocabulary are retained. The portable **G4Speak.exe** and **SHA256SUMS.txt** are also included.

## Enhanced proofreading fix

- Fix proofreading requests being rejected on Groq accounts with a 1,000 output tokens per minute limit. Previously, every request reserved at least 1,024 tokens, causing even short dictations to fail.
- Scale the output budget with transcript length and cap each request at 1,000 tokens.
- Add regression coverage for short and long Thai transcripts under the account limit.

Speech recognition continues to use Whisper Large-v3. Enhanced proofreading uses Qwen 3.8 27B. Genuine quota exhaustion or service failures can still trigger the notification; the original transcription is preserved when proofreading is unavailable or incomplete.
