## Install

Download **G4Speak-Setup-1.3.1.exe** and run Setup. Existing API settings and personal vocabulary are retained. The portable **G4Speak.exe** and **SHA256SUMS.txt** are also included.

## More reliable Thai and technical-term proofreading

- Prevent short Qwen answers from exhausting their output budget on reasoning. Reconsider rejected answers with supporting vocabulary once, within the existing deadline and token allowance.
- Split long transcripts using UTF-8 byte limits, preserve Thai combining marks, and provide neighboring speech as read-only context.
- Reject substantial unsupported Thai word substitutions even when the surrounding sentence is unchanged. Retain numbers, negations, identifiers, and the original transcript on unsafe edits or service failures.
- Add a repeatable cloud accuracy evaluator and an optional public Thai speech sample downloader.

The development text corpus matched 72/72 references over three cloud rounds; the final Thai guard retained all recorded outputs. On six public Thai speech samples, the final pipeline reduced character error rate from 10.60% for raw recognition to 6.04%, with no sample worse than raw recognition. These small development samples do not establish accuracy for every speaker, microphone, or specialized term. See [evaluation details](https://github.com/Vichaya-Lab/g4speak/blob/v1.3.1/docs/accuracy-evaluation.md).

Speech recognition continues to use Whisper Large-v3 and proofreading uses Qwen 3.8 27B. No hosted model weights were trained. GitHub Actions builds the release and verifies installation, upgrade from v1.3.0, settings preservation, startup, and uninstall before publishing.
